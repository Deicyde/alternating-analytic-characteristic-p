# Ingleton extension and the norm-one scalar projection

Let K₁ be a spherically complete ultrametric normed field. If V is an ultrametric normed K₁-space, V₀⊆V and T₀:V₀→K₁ is linear with |T₀x|≤C‖x‖ for C≥0, then T₀ extends linearly to V with the same bound. In particular, for an ultrametric extension K'⊇K₁ there is a bounded K₁-linear retraction varpi:K'→K₁ with ‖varpi‖≤1 and varpi|K₁=id.

## Proof

For a one-dimensional domain extension, seek the value of a new vector inside the family of balls centered at values forced by old vectors with radii prescribed by the bound. The ultrametric inequalities make every pair of these balls intersect; spherical completeness provides a common value, which defines a compatible bounded extension. Order bounded partial extensions by inclusion. The union of a chain is a bounded partial extension. Zorn's lemma gives a maximal extension, and the one-dimensional step shows its domain is all of V. For the projection, take V=K', V₀=K₁, T₀=id and C=1. This theorem is used only on the ultrametric scalar domain K', never on a potentially non-ultrametric Banach target.
