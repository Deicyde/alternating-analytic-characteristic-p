# No bounded-support finite-field multiplier lift

Let L be a finite field and k≥1 with (k!:L)=0. There is no 2k-linear map Ψ:Vfin^k×Vfin^k→Λ^k_L V, V=L^ℕ and Vfin=L^(ℕ), antisymmetric in the final k slots, satisfying Pol1 for coordinatewise multipliers and a uniform bound sdim(Ψ(u;x))≤d on inputs with coordinates in {0,1,-1}.

Use infinite order-pattern homogeneity, actual cluster cancellation and staircase rank to show adjacent cluster invariance. Adjacent transpositions generate the symmetric group, so the actual cluster values are constant. Their polarized diagonal sum is one; the same sum equals k! times a constant, hence zero, contradiction.

The all-sequence and finite-sequence restriction consequences are recorded separately.
