# The constructed target has no equivalent ultrametric norm

The Banach space B from the block-wedge construction admits no equivalent ultrametric norm. The same holds for its completed scalar extension F=B completed-tensor-π K' under the scalar-extension hypotheses, as a space over K' or any subfield with the restricted norm.

## Proof

Suppose an equivalent ultrametric norm ‖·‖u obeyed ‖x‖B≤c‖x‖u≤c'‖x‖B. Then ‖∑_{j<N}ω_j‖B≤c max_{j<N}‖ω_j‖u≤c' for every N. This contradicts the lower bound N/M_r. This argument uses only the ultrametric triangle inequality and the norm equivalence, not scalar homogeneity. The canonical embedding B→F is a linear isometry, so the images of the same ω_j satisfy identical norms and lower bounds in F. Restricting scalar fields leaves these norm estimates unchanged.
