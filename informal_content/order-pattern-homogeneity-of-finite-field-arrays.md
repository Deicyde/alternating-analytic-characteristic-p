# Order-pattern homogeneity of finite-field arrays

For N≥1, a finite field L and T:ℕ^N→L, there exists an infinite H⊆ℕ such that T(z)=T(z') whenever z,z'∈H^N have identical equality and order comparisons between all coordinates.

## Proof

Color each increasing N-element set {s₁<⋯<s_N} by the vector (T(s_{β(1)},…,s_{β(N)})) over all maps β:[N]→[N]. This is a finite color space. Obtain an infinite homogeneous H by Ramsey. For a tuple z in H^N, list its r distinct values increasingly and pad this list with N-r elements of H larger than all of them. It becomes the initial segment of an N-element set; z is selected from that set by the rank map β determined solely by its pattern. The corresponding component of the homogeneous color is T(z).
