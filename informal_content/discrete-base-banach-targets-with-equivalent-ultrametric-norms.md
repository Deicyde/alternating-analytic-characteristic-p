# Discrete-base Banach targets with equivalent ultrametric norms

Let K be an ultrametric nontrivially normed field with |K×|=r^Z for 0<r<1. If a K-Banach target F admits an equivalent ultrametric norm, then Q^K_{E,E',F} is analytic everywhere for all normed E,E'. Completeness of K is not required.

## Proof

Round the equivalent ultrametric norm upward to the least r-power dominating each positive value, sending zero to zero. The rounded norm lies between the original ultrametric norm and r^(-1) times it. Rounding is monotone and commutes with multiplication by r-powers, so it remains a homogeneous ultrametric norm. Equivalence preserves completeness, and its metric takes values in r^Z∪{0}; hence the target is spherically complete. Apply the quoted spherical-target theorem. Finally transfer analyticity back along the identity between equivalent target norms. The induced norms on alternating maps and on linear maps between them are equivalent with uniform constants, so a convergent bounded-coefficient power series remains one for the original norms.
