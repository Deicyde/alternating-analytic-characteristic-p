# Cluster coefficients and order-pattern values

Let V=L^ℕ, Vfin=L^(ℕ), and let Ψ:Vfin^k×Vfin^k→Λ^kV satisfy the multiplier obstruction hypotheses. Put T(a;y;c)=Ω(Ψ(e_a;e_y))(c). On an infinite set H homogeneous for its 3k-coordinate patterns, a cluster is four consecutive elements C(0)<⋯<C(3) of H. Define s_C=∑s_i e_{C(i)} and w_C=∑w_i e_{C(i)}. For pairwise disjoint clusters C₁,…,C_k, put χ(C)=Ω(Ψ(s_{C₁},…,s_{C_k};w_{C₁},…,w_{C_k}))(C₁(0),…,C_k(0)). This depends only on the permutation τ giving the order of the labeled clusters.

## Proof

Expand each finitely supported operator and vector input into unit vectors. Multilinearity gives Ω(Ψ(u;v))(c)=∑_{a,y}∏_j u_j(a_j)∏_j v_j(y_j)T(a;y;c), a finite sum. In the cluster expansion each term is determined by a pair of internal positions in each cluster. Comparisons between different clusters are determined by τ and those within a cluster by the internal positions. Pattern homogeneity therefore makes the entire weighted sum depend only on τ. Consecutiveness ensures that all outside H-indices lie wholly below or wholly above each cluster.
